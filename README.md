# Capstone Project: AI-Assisted VBA to Web Application Migration

## 📌 Overview

This project explores the use of **Generative AI (LLMs)** to transform traditional **Excel spreadsheets with VBA macros** into modern, scalable **web applications**.

Western Sydney University currently relies on Excel + VBA for workload grading, which is:

* Manual and time-consuming
* Prone to human errors and inconsistencies
* Difficult to maintain and debug

This project evaluates whether tools like **ChatGPT, Gemini, and Claude** can automate and improve this transformation process.
---

This project is for academic and research purposes.

---

## 🎯 Objectives

* Analyze limitations of existing Excel-VBA systems
* Break down complex VBA logic into modular components
* Use structured prompting with LLMs to generate web-based solutions
* Convert VBA logic into **React.js applications**
* Compare AI-generated outputs against a **gold-standard prototype**
* Evaluate accuracy, consistency, and feasibility

---

## 🛠️ Methodology

### 1. System Analysis

* Studied existing Excel + VBA workload system
* Identified key issues:

  * Fragile VBA code
  * Difficult debugging
  * Manual workload adjustments

### 2. Modularization

* Segmented large VBA macros into smaller, testable modules

### 3. Prompt Engineering

* Designed structured prompts for:

  * Workload calculations
  * Allocation logic
  * Data handling
* Ensured consistency across multiple LLMs

### 4. AI Code Generation

* Used LLMs to convert VBA logic into:

  * React.js components
  * Functional web-based workflows

### 5. Prototype Development

* Built a **gold-standard reference system**
* Used as a benchmark for evaluation

### 6. Testing & Validation

* Compared AI-generated outputs with prototype
* Test cases included:

  * Workload distribution calculations
  * Error handling
  * Data accuracy
  * UI consistency

---

## ⚙️ Technologies Used

* **Frontend:** React.js
* **AI Models:** ChatGPT, Gemini, Claude
* **Source System:** Excel VBA
* **Testing:** Manual validation & comparison

---

## 📊 Key Features

* AI-generated React implementations of workload systems
* Modular translation of VBA logic
* Structured prompt framework for reproducibility
* Comparative evaluation across multiple LLMs

---

## 📈 Results

* All LLMs generated functional React code but required human intervention to fix errors, ensure security, and manage complex logic
* Output quality varied across models
* AI significantly reduced manual effort
* Demonstrated strong potential for:

  * Automation
  * Error reduction
  * Supporting and speeding development 

---

## ⚠️ Challenges

* Inconsistent outputs between models
* Need for manual validation
* Complex VBA logic translation
* UI and logic mismatches in generated code
* Integration with backend and third party application

---

## 🚀 Future Work

* Improve prompt engineering strategies
* Expand dataset and use cases
